# Changelog

Every release of Blueprint Helper, newest first. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and versions follow [Semantic Versioning](https://semver.org/). Each entry is also the release note on Mod.io.

## [1.0.0] - 2026-10-20

The first release.

### Added

- Guide mode: after each graded arrangement, the two slots to swap next, outlined in blue on the Discovery window and
  marked in the panel. Following the suggestions reaches Perfect within 11 swaps on every blueprint, about 7 on average.
- Once only one Perfect arrangement is left, a green slot number on every module that is out of place, on the track and
  beside it.
- Logbook mode: the readings and history without suggestions.
- Prototyping help: the modules each Prototype confirmed, outlined green on the board and counted.
- A history of every arrangement tried and the level it scored, with module icons or, in compact mode, level names only.
- Memory per blueprint while the plugin is enabled: switching blueprints and back restores readings, prototyping
  progress and the solution.
- "Readings disagree" when no hidden ranking fits every reading, with an undo icon to drop the newest reading.
- Settings for the mode, the outlines, the XP percentage and compact history, and "Reset all data".
